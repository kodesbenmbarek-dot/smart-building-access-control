# Smart Building Access Control System

## 📝 Overview
An embedded access control system designed for **Smart Building** applications using **Arduino**. The system manages door access control, visual status reporting, and wireless communication interface.

## 🛠️ Hardware Components
- **Microcontroller:** Arduino Uno
- **Display:** I2C LCD Screen (16x2)
- **Actuators:** Status LEDs (Green/Red), Door Lock Trigger / Servo Motor
- **Inputs:** Access Control Button / Wireless Command Signal
- **Communication:** Wireless Interface Module

## 🚀 Key Features
- Automated door status management (Locked / Access Granted).
- Real-time visual feedback via LCD display and status LEDs.
- Modular C/C++ embedded code design.

## 📁 Project Structure
- `src/` : Contains Arduino C++ source code (`.ino`).
- `docs/` : Circuit schematics and documentation.
